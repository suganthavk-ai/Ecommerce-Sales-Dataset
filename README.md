# Ecommerce-Sales-Dataset
The Ecommerce Sales Analysis Project focuses on cleaning, transforming, and analyzing ecommerce sales data.
# Description
This project is a complete data analytics workflow built entirely in Microsoft Excel. It simulates a real-world business scenario where raw e-commerce data (Customer, Product, Store, and Sales details) is cleaned, transformed, and analyzed to generate a strategic sales dashboard.

## Project Objectives
- Check and handle missing values.
- Standardize text formatting.
- Format date values consistently.
- Identify and correct inconsistencies.
- Apply conditional formatting rules.
- Improve data quality for reporting and analysis.

## Dataset Description
The dataset consists of product inventory information with the following fields:

| Column Name | Description |
|------------|-------------|
| Order ID | Unique identifier for each order |
| Order | Date when the order was placed |
| Customer ID | Unique identifier for each customer |
| Customer Name | Name of the customer |
| Product Name | Name of the product purchased |
| Category | Product category |
| Quantity | Number of units sold |
| Unit Price | Price per unit of the product |
| Discount | Discount applied to the order |
| Sales/Revenue | Total revenue generated from the sale |
|Region | Area of the customer or sale |
| Shipping Information | Details related to product delivery |

# Installation
1.	Download the Ecommerce Sales Dataset.xlsx file.
2.	Open the file in Microsoft Excel (Office 365 or newer version recommended).
3.	Explore the sheets in the following order to understand the workflow:
o	Customer Details, Product Details, Store Details, Sales Details: View the raw and cleaned data, along with the formulas used for transformation.
o	Formulas & Functions: Review specific examples of key formulas like VLOOKUP and IF().
o	Sum of Sales, Year wise sales, Profit by category: Examine the PivotTables for aggregated analysis.
o	Dashboard: Interact with the final, visual summary of the insights.

## Key Business Insights
-	Based on the analysis performed on the cleaned data:
-	Total Revenue reached $2.55 million** with a total profit of **$1.27 million.
-	Sales Trend: 2024 was the strongest year, contributing nearly 50% of the total revenue.
-	Regional Performance: The South and North regions are the top performers, each generating over $110k in sales for the Clothing category alone.
-	Payment Methods: Credit Card transactions have the highest average order value ($1,108), slightly ahead of PayPal ($1,088) and COD ($1,066).
-	Product Category: The Sports category has the highest number of units sold (498 transactions), while Electronics has the highest total cost of goods sold, indicating a high-value category.
